 🐍 Comprehensive Python Fundamentals Course




Welcome to the \*\*Principles of Python Course\*\*! This repository contains a series of structured Jupyter Notebooks designed to guide beginners through the core concepts of Python programming, from basic syntax to Object-Oriented Programming (OOP).



Whether you are new to coding or looking to refresh your knowledge, these notebooks provide clear explanations and practical examples.



\##  Table of Contents



The course is divided into logical modules covering the following topics:



\### 1. Introduction \& Basics

\- Interpreted vs. Compiled Languages

\- Variables \& Naming Conventions

\- Assignments (`=`)

\- Data Types (Integer, Float, String, etc.)

\- Type Casting

\- Basic Operators



\### 2. Logic \& Control Flow

\- Boolean Type \& Operators

\- Conditional Statements (`if`, `if-else`)

\- Bitwise Operators

\- Operator Precedence \& Associativity

\- \*\*Practice:\*\* Simple programs \& examples



\### 3. Loops \& Iteration

\- `while` Loop

\- `for` Loop

\- Loop Control (`break`, `continue`, `pass`)

\- \*\*Practice:\*\* Writing iterative programs



\### 4. Data Structures

\- \*\*Lists:\*\* Ordered, mutable collections

\- \*\*Tuples:\*\* Ordered, immutable collections

\- \*\*Sets:\*\* Unordered, unique collections

\- \*\*Dictionaries:\*\* Key-Value pairs

\- \*\*Strings:\*\* Immutable text sequences (Slicing \& Indexing)



\### 5. Functions \& Functional Programming

\- Defining Functions

\- Parameters \& Arguments

\- Variable Scope (Global vs. Local)

\- Recursion

\- Lambda Functions, `map()`, \& `filter()`



\### 6. File Handling (I/O)

\- Introduction to File I/O

\- The `open()` function \& modes

\- Reading \& Writing files

\- Context Managers (`with` statement)

\- Working with \*\*CSV\*\* files

\- Working with \*\*JSON\*\* files



\### 7. Exception Handling

\- Understanding Exceptions \& Error Types

\- `try`, `except`, `else`, `finally` blocks

\- Catching general exceptions

\- Exception Hierarchy

\- Custom Exceptions



\### 8. Object-Oriented Programming (OOP)

\- Procedural vs. OOP approach

\- Classes \& Objects

\- Attributes \& Methods

\- The Constructor (`\_\_init\_\_`)

\- The `self` keyword



\### 9. Advanced OOP (Inheritance)

\- Inheritance Concepts (Parent \& Child classes)

\- Polymorphism

\- Types of Inheritance

\- Abstract Classes

\- \*\*Project:\*\* Comprehensive OOP Example




\## 🚀 How to Use This Repository



1\. \*\*Clone the repository:\*\*

&nbsp;  ```bash

&nbsp;  git clone https://github.com/Nimasol42/principles-of-python.git

&nbsp;  ```



2\. \*\*Install Jupyter Notebook (if not installed):\*\*

&nbsp;  ```bash

&nbsp;  pip install notebook

&nbsp;  ```



3\. \*\*Navigate to the directory and start Jupyter:\*\*

&nbsp;  ```bash

&nbsp;  cd principles-of-python

&nbsp;  jupyter notebook

&nbsp;  ```
